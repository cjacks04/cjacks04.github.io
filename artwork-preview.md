  <p>This preview shows how the decorative artwork can sit in the upper-right corner of a standard website page while the main content remains inside the centered site width.</p>

  <h2>Sample Section</h2>

  <p>The artwork is positioned independently of the page text so it can act as a visual accent without changing the reading width. On smaller screens, it moves into the normal document flow so it does not overlap headings or body text.</p>

  <p>If this placement works well, the same treatment can be added to the main page layout so the artwork can appear consistently across selected pages.</p>
